# JourneyFrame

**AI-powered conversational trip planner delivered through iMessage.**

Text a message like *"My friend Sarah is visiting Seattle tomorrow. Plan a cozy rainy-day afternoon for us."* — and JourneyFrame texts back a warm, personalized itinerary with a cinematic travel poster.

---

## Demo

**Input (iMessage):**
> My friend Sarah is visiting Seattle tomorrow. Plan a cozy rainy-day afternoon for us.

**Output:**

![JourneyFrame Seattle itinerary poster](demo/journey-scene.png)

JourneyFrame replies with:
- 2–4 warm iMessage-style messages describing each stop
- A cinematic travel poster generated by gpt-image-2
- A prompt to generate more images on demand

---

## How It Works

```
iMessage → Photon Spectrum → FastAPI Backend → RocketRide Pipeline → gpt-image-2 → iMessage
```

### RocketRide 6-Stage Wave Pipeline

| Stage | Node | What It Does |
|---|---|---|
| 1 | Intent Parser | Extracts location, occasion, relationship, vibe, time, constraints |
| 2 | Context Enricher | Adds weather context, preferences, relationship tone, local tips |
| 3 | Itinerary Planner | Generates 3–5 stops with emotional purpose |
| 4 | Experience Narrator | Writes warm iMessage-style messages |
| 5 | Image Prompt Generator | Creates a cinematic travel poster prompt |
| 6 | Response Composer | Assembles final iMessage-ready response |

Stages 4 and 5 run **in parallel** within the same RocketRide wave.

## Setup

### 1. Backend
```bash
cd backend
cp .env.example .env      # fill in ANTHROPIC_API_KEY, OPENAI_API_KEY
pip install -r requirements.txt
uvicorn main:app --port 8000
```

### 2. Spectrum Gateway (iMessage)
```bash
cd spectrum
cp .env.example .env      # fill in PHOTON_PROJECT_ID, PHOTON_PROJECT_SECRET
npm install
npm run dev
```

### 3. RocketRide Pipeline
1. Install the [RocketRide VS Code extension](https://marketplace.visualstudio.com/items?itemName=RocketRide.rocketride)
2. In the RocketRide sidebar, click **Deploy → Local** to start the local server on `localhost:5565`
3. Set `ROCKETRIDE_APIKEY=local` in `backend/.env`

All three services must be running for end-to-end delivery.
